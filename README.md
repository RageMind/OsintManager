# OsintManager

Локальная панель для работы с разрешёнными публичными источниками и экспериментального игрового агента. Python 3.11, без npm, сборки фронтенда и LangChain.

## Установка

Команды из корня проекта:

    python3.11 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    playwright install chromium
    cp .env.example .env

Windows: активировать окружение командой .venv\Scripts\activate, копировать файл командой copy .env.example .env. Указать OPENAI_BASE_URL, OPENAI_API_KEY, OPENAI_MODEL. Для неподдерживающих JSON response_format провайдеров может потребоваться совместимый шлюз.

Запуск панели:

    python -m agent.main --ui

Адрес: http://127.0.0.1:8000. По умолчанию доступен только на текущем компьютере. Для VPS используйте SSH-туннель: ssh -L 8000:127.0.0.1:8000 user@server. Не выставляйте порт напрямую в интернет. Если UI_HOST отличается от localhost, APP_TOKEN обязателен. При первом ответе 401 браузер запросит токен.

## Исследовательский режим

Создайте UTF-8 targets.txt с одним разрешённым публичным URL, названием публичной организации/проекта или управляемым вами аккаунтом на строку:

    https://github.com/python
    python

Запуск:

    python -m agent.main --mode osint --targets targets.txt

Планировщик работает через OpenAI-совместимый API и предлагает ограниченный список адресов. Исполнитель проверяет домены по OSINT_ALLOWED_HOSTS, запрещает приватные IP-адреса и сначала открывает страницы в Chromium, затем пытается безопасный HTTP/HTML fallback. Ошибка одного источника не прерывает остальные цели. Повторная обработка той же цели обновляет исходные доказательства в таблице source_records. После завершения очереди resolve_all собирает канонические профили с порогом OSINT_RESOLVE_THRESHOLD (по умолчанию 0.75). Идентичность не устанавливается по одному лишь ФИО. Совпадающие email, номера и хэндлы имеют вес 1.0, 0.95 и 0.8. Совпадение ФИО и города имеет вес 0.6, только ФИО - 0.3. Модель не извлекает не подтверждённые самой страницей факты.

Поддерживается точная структура профиля (включая поля id, names, handles, emails, phones, locations, work, education, socials, interests, relations, sources, conflicts, raw_snippets). Автоматическое извлечение ограничено публичной профессиональной метаинформацией; частные контакты, адреса и предположительные отношения не собираются. Схема дополнена derived, method, facts, preferred, derived_facts. Исходные значения и ссылки источников не замещаются нормализованными или предполагаемыми: нормализация записывается отдельно как derived=true. Мультицелевое объединение отмечено method=entity_resolution. Рёбра графа same_person/associate строятся по двум и более совпавшим атрибутам, помечены derived=true и имеют собственные evidence, method, confidence. При этом отдельное совпадение города или фамилии не подтверждает личную связь. Достоверность утверждений из LLM следует проверять по сохранённым источникам.

Результаты: data/manager.sqlite3 и reports/*.json, reports/*.html, reports/graph.json. CSV доступен через кнопку на панели.

OSINT_ALLOWED_HOSTS определяет разрешённые домены, OSINT_MAX_PAGES - число страниц, OSINT_TIMEOUT - таймаут страницы, OSINT_MAX_CHARS - максимальную длину текста, OSINT_DELAY - паузу. Селекторы видимого текста меняются в agent/executor.py (функции fetch_page, visible_html), а инструкции модели - в prompts/*.md или во вкладке «Настройки».

## Игровой режим

    python -m agent.main --mode game --fps 2

Нужен рабочий графический сеанс с доступным экраном (X11/Windows), Chromium не требуется. На безголовом VPS без виртуального дисплея захват не работает. В зависимости от ОС глобальные горячие клавиши Esc/F10 модулем keyboard могут требовать дополнительные права; доступен аварийный стоп через панель и стандартный PyAutoGUI FAILSAFE (перемещение мыши в верхний левый угол). Разрешён только ограниченный набор действий wait/move/click/press. Никакой гарантии обхода античита, совместимости с правилами конкретной игры или работы с фоновым окном нет.

## Панель и API

Семь вкладок: Дашборд, Цели, Профили, Граф, Логи, Игра, Настройки. События status/log/profile/game_frame/error доставляются через /ws. REST доступен по /api; /api/config скрывает существующие ключи маской. Изменения настроек применяются после остановки активной задачи. Экспорт профилей производится по /api/profiles/export?format=json|csv. Полный перечень эндпоинтов находится в agent/api.py.

Секреты никогда не добавляйте в репозиторий. Файл .env исключён через .gitignore. Содержимое внешних страниц недоверенное; не предоставляйте агенту доступ к чужим закрытым аккаунтам, и не используйте полученные сведения для преследования или деанонимизации.
